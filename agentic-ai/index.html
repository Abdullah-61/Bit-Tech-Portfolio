Graphiti + Neo4j AuraDB

Graphiti Python library manages episode storage and retrieval. Neo4j AuraDB is the hosted graph database — free tier, zero infrastructure management.

Graph Embeddings

Azure OpenAI text embedder generates graph embeddings for semantic search within the graph — enabling similarity-based context retrieval beyond exact-match queries.

Session Management

initialize_memory() and clear_session() provide clean session lifecycle management. Conversation IDs route between multiple distinct agent conversations per user.

How we deliver

  • Capture conversations: Each interaction is added as an episode in the graph.
  • Persist entities: People, preferences, and relationships are materialised as graph primitives.
  • Retrieve context: get_context() fetches relevant summaries and links per request.
  • Inject into prompts: Graph context is inserted before generation, every turn.
  • Keep sessions clean: IDs and lifecycle functions isolate conversations safely.
  • Improve continuity: Responses become increasingly personalised over time.

Capability 2

5 Integrated Data Sources

Each source adds real-world grounding to agent responses, enabling decision support with current external context.

ScrapeGraphAI Ticketmaster API Eventbrite API Gutendex OpenLibrary

ScrapeGraphAI

Location-aware data scraped by region and cached to reduce repeated lookups. Chromedriver deployed on Azure VM.

Ticketmaster API

External events and listings by location/date, integrated as real-time planning context.

Eventbrite API

Secondary events source for broader local coverage. Integrated as fallback and supplemental data source.

Gutendex API

Primary book source. Robust handling with exception management, deduplication, and age-based filtering.

OpenLibrary

Fallback book source when Gutendex results are insufficient — automatic fallover, transparent to user.

How we deliver

  • Capture inputs: User intent, profile, and constraints flow into one orchestration request.
  • Recall memory: Agent queries graph context before generating each response.
  • Enrich in parallel: Places, events, and books are fetched concurrently from external APIs.
  • Apply fallback chains: Secondary providers activate automatically when primary sources are weak.
  • Synthesize with LLM: GPT-4o combines graph + live data into contextual recommendations.
  • Stream to UI: SSE returns incremental responses for a conversational experience.
