How we deliver

  • Collect intent: User describes logo/style in plain language.
  • Generate art: DALL·E 3 creates assets (with fallback options if needed).
  • Process image: Background removal, warp, and compositing align design to fabric geometry.
  • Store outputs: Mockups and assets persist in Azure Blob with shareable links.
  • Route lead: Make.com webhook sends quote payload to CRM and email follow-up.

Technical Depth

Built on production-grade technology

For teams that want to know what's under the hood.

AI Logo Generation

Azure OpenAI DALL·E 3 — text-to-image via structured prompt engineering with style and format controls.

Background Removal

rembg + ONNX Runtime — ML-based background removal with no manual selection required.

Perspective Correction

Custom grid-based mesh transform (Pillow) to match logo curvature to shirt fabric realistically.

Cloud Storage

Azure Blob Storage for generated logos and mockups — persistent, shareable URLs for CRM and email.

CRM Automation

Make.com webhook integration routes quote payloads (name, email, phone, logo URL, mockup URL) to any CRM.

Azure Deployment

Deployed on Azure VM with systemd, automated via Makefile pipeline — build, package, sync, restart.
