Workflow 01
News Summarizer & LinkedIn Auto-Publisher
Scrapes live news headlines from Dawn News, summarizes using Azure OpenAI GPT-4, and posts directly to LinkedIn — on a single click trigger.
n8n Azure OpenAI LinkedIn API Web Scraping CSS Selectors
n8n Workflow Canvas

How we deliver

  • Manual trigger fires the workflow on-demand
  • HTTP Request node scrapes Dawn News homepage
  • CSS selectors extract headlines & excerpts (.story__title, .story__excerpt)
  • Summarization Chain with Default Data Loader + Recursive Text Splitter
  • Azure OpenAI GPT-4 condenses content into a concise summary
  • Merge node combines extracted title + summary into clean post
  • LinkedIn node publishes directly to the connected account

Platform capabilities

Resilient scraping

Error-handling branch catches failed HTTP requests before downstream steps run.

Person or org posting

Publish as a LinkedIn member profile or an Organization page from one workflow.

Formatted output

Edit Fields node shapes title, summary, and post body before publishing.

LinkedIn OAuth

OAuth2 credentials managed in n8n for secure API access.

Swap-in sources

Reusable pipeline — point the HTTP node at any news URL without rework.

Workflow 02
News Summarizer with Odoo CRM & Human-in-the-Loop
Dynamic pipeline triggered by a Google Sheet. Scrapes, summarizes, routes through Gmail for human approval, then publishes to LinkedIn & Facebook — while syncing media contacts to Odoo CRM.
n8n Azure OpenAI Odoo CRM LinkedIn API Facebook API Google Sheets Gmail
n8n Workflow Canvas

How we deliver

  • Google Sheets Trigger fires when a new news source row is added
  • HTTP Request scrapes the URL provided in the sheet row
  • Azure OpenAI summarizes the scraped content
  • Gmail "Send and Wait" pauses workflow for human editorial approval
  • Approve/Disapprove buttons directly in the approval email
  • On approval: simultaneous post to LinkedIn & Facebook
  • Editor contact added/updated in Odoo CRM automatically

Platform capabilities

Editorial gate

Human-in-the-loop approval so nothing publishes before a reviewer signs off.

Multi-network publish

Single execution posts to LinkedIn and Facebook when approved.

Odoo CRM sync

Every news-source contact is created or updated in Odoo automatically.

Sheet-driven runs

Add a URL and contact row — the pipeline picks it up without code changes.

Clean rejection

Disapprove from email stops the flow with no partial or duplicate posts.

Workflow 03
Multi-Platform AI Content Generator & Analyzer
Takes a user prompt + optional reference images and generates SEO-optimized, platform-tailored content across LinkedIn, Facebook, news articles, and video scripts — with a self-QA loop and human review gate.
n8n Azure OpenAI LinkedIn Facebook RAG / Vector DB SEO SerpApi RSS Feeds
n8n Workflow Canvas — Multi-Step Pipeline

How we deliver

  • User submits prompt (text + optional reference images)
  • RAG retrieves relevant SEO keywords & brand rules from vector DB
  • Separate LLM prompts produce platform-specific content variants
  • Self-QA loop: LLM scores each output against brand rules
  • Non-compliant pieces are auto-regenerated before human review
  • Email approval gate for final editorial sign-off
  • Images uploaded by reviewer or generated via DALL-E / Stability AI
  • All approved content published to each platform

Platform capabilities

Channel-aware copy

Short social posts vs long articles — length and tone tuned per destination.

SEO from the DB

Similarity search injects live SEO keywords from your vector store.

Self-QA loop

LLM scores its own drafts against brand rules before human review.

Auto keyword refresh

RSS subscriptions keep the keyword / rules database current.

Live search context

SerpApi augments each prompt with fresh search context.

Composable flows

Platform sub-flows can run independently or as part of the full pipeline.
